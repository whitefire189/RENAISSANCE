Renaissance - A study/research/deepwork oriented webOS, having medieval dark academic/scholar theme. 

NOTE:- this is documented for tracking the development of this project from 3rd-6th Oct 2026, the project is still in its initial development phase.


This is the link to try the project built so far - https://whitefire189.github.io/RENAISSANCE/


Functioning of the project in this period:
It is a plain brown colored webpage with basic buttons that do not function or result in any output by clicking yet, features yet to be added soon.

How to run: there is nothing functionable or anything to run yet, but you can check out how it looks by clicking the link above

Design decision- for the main vision of this OS, the design is based on the dark academic aesthetic that we often get to see in fantasy stories, but never to experience. This OS is created to offer the user a working/study environment, different from the modern "bright", "neon" , "chaotic" ideas.

No arts and assets are used in the project, hence no credits are given out yet.
